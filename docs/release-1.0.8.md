# Benger 1.0.8 — posiłki, pomiary i treningi

W Więcej → Ustawienia → Powiadomienia i przypomnienia można osobno włączyć śniadanie, obiad, kolację, przekąskę, wagę, ciśnienie/tętno i obwody. Każde ma godzinę i dni tygodnia. Domyślnie nowe przypomnienia są wyłączone. Test powiadomienia pozwala sprawdzić pasek telefonu i wejście do odpowiedniego ekranu.

Treningi i Mobility pozostają związane z kalendarzem i mają własne wyprzedzenie oraz godzinę domyślną. Dotychczasowe ustawienia są odczytywane bez zmian; po zapisie trafiają do trwałej pamięci objętej backupem.

Posiłki i pomiary korzystają z powtarzających się lokalnych alarmów Androida, również przy zamkniętym Bengerze i bez internetu. Nie wymagają codziennego uruchamiania. Android może opóźnić dostarczenie, szczególnie podczas oszczędzania baterii lub uśpienia. Tryb Nie przeszkadzać i ustawienia kanałów sterują dźwiękiem. Nie prosimy o uprawnienie do dokładnych alarmów.

Kliknięcie otwiera dzisiejszy dziennik z wybranym posiłkiem albo istniejący formularz pomiaru. Nie zapisuje jedzenia ani wyniku pomiaru automatycznie; niezapisane pola pomiaru pozostają zachowane. Nie uruchamia mikrofonu ani aparatu.

Kanały Androida: Trening i Mobility, Posiłki, Pomiary. Każdy można wyciszyć w telefonie. Po zmianie strefy czasowej otwórz Bengera, aby przeliczyć najbliższe terminy. Wymuszone zatrzymanie APK blokuje przypomnienia do ponownego otwarcia. Przypomnienia treningowe nadal mają 60-dniowy horyzont odświeżany po uruchomieniu aplikacji.

Backup v8 z opcjonalnym polem notificationPreferences obejmuje obie grupy ustawień. Import starych kopii v1–v8 zachowuje obecne preferencje. Import używa istniejącego mechanizmu rollbacku; błąd nie pozostawia częściowo zmienionych ustawień. Zgody Androida nie są częścią backupu.

Ten sam applicationId, origin, bazy i podpis co APK 1.0.6/1.0.7. Aktualizacja odbywa się bez odinstalowania. Bez backendu, płatnych usług, telemetrii i zmian Workera AI. Wersja przeglądarkowa nie planuje systemowych alarmów.

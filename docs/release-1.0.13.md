# Benger 1.0.13 — składniki ze screena

W aplikacji Android otwórz Przepisy → Nowy przepis (lub edycję istniejącego) → Wczytaj składniki ze screena. Wybierz zdjęcie, sprawdź listę i dodaj zaznaczone składniki do szkicu. Nazwy, ilości i jednostki można poprawić przed zapisem.

Odczyt działa na urządzeniu bez wysyłania obrazów. Niepełne dane wymagają uzupełnienia; Benger nie zgaduje kalorii ani masy sztuki. Dla najlepszego wyniku wybierz wyraźny screen samej listy składników. Aktualizacja zachowuje dane, przepisy i historię. Wersja webowa pozostaje bez zmian.

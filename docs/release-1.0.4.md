# Benger 1.0.4

Hotfix aktualizacji PWA.

- Benger aktywnie sprawdza nową wersję Service Workera przy uruchomieniu aplikacji.
- Ponowne połączenie z internetem również uruchamia kontrolę aktualizacji.
- Aktualizacja nadal nie przeładowuje aplikacji bez zgody użytkownika.
- Brak sieci lub błąd kontroli aktualizacji nie blokuje działania offline ani danych lokalnych.

# Benger 1.0.14 — czytelniejsze, interaktywne wykresy

- Dotknij wykresu, aby odczytać datę i dokładne wartości. Przyciski pozwalają przechodzić między terminami bez celowania w mały punkt.
- Zmieniaj zakres 7/30/90 dni, ukrywaj serie i powiększaj wykres. Dostępna jest też tabela wartości.
- Masa, obwody, ciśnienie i progres ćwiczeń korzystają z rzeczywistych dat. Dla pomiarów zdrowotnych zachowujemy również godziny.
- Ciśnienie ma skalę mmHg, a tętno osobną skalę ud./min. Bez diagnozowania lub klasyfikowania pomiarów.
- Dziennik pokazuje historyczne cele na dzień ich obowiązywania; możesz przełączać wykres między białkiem, tłuszczem i węglowodanami. Brak dnia w dzienniku nie jest traktowany jak 0 kcal.
- Podsumowanie zawiera średnią widocznych punktów, min/max i zmianę pierwszego względem ostatniego. Średnia punktów obejmuje zapisane pomiary/wpisy, nie niezapisane dni.
- Wersja zawiera również import składników ze screenów z 1.0.13.

Dane pozostają lokalne, struktura backupu i historia nie zmieniają się. Nie trzeba instalować pośredniej wersji 1.0.13. Nie dodano usług ani zależności sieciowych.

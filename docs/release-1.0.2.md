# Benger 1.0.2

Hotfix mobilnego widoku Progresu.

- Historia pomiarów nie używa już dwukolumnowej karty z Dziennika.
- Ciśnienie jest prezentowane jako czytelne 120/80 mmHg, a puls osobno.
- Data, godzina i pora pomiaru są w jednym nagłówku.
- Notatka zajmuje pełną szerokość i nie nachodzi na metadane.
- Przyciski Edytuj / Usuń mają stabilny układ na telefonie.
- Analogiczny układ stosowany jest dla wagi i obwodów.

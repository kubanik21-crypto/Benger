# Benger 1.0.5

Dopracowany edytor przepisów bez AI:

- Dodawanie produktu z katalogu bez interpretowania wypowiedzi.
- Ręczna poprawa produktu, ilości i jednostki z podglądem makro.
- Przestawianie kroków przygotowania.
- Opcjonalny czas i temperatura w krokach, widoczne także w gotowym przepisie.
- Zachowane szkice, wersje, historyczne snapshoty dziennika i backup v7.
- Działanie offline, bez nowego backendu, kont, kluczy i płatnych usług.

Aktualizacja PWA zachowuje produkcyjne dane i wymaga standardowego zaakceptowania nowej wersji w aplikacji. Dokumentacja: [edytor przepisów](recipe-editor.md).

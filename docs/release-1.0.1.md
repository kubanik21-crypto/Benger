# Benger 1.0.1

Hotfix polskiego języka produktów.

- Rozszerzona bezpieczna normalizacja odmian popularnych nazw żywności.
- `409 gram mąki` → `maka`, 409 g.
- Obsługiwane są m.in. odmiany mąki, twarogu, kaszy, pomidorów, mięsa, piersi z kurczaka i wielu innych podstawowych produktów.
- Dodane formy częstych określeń, np. `mąki pszennej` → `maka pszenna`.
- Nie zmieniono źródeł wartości odżywczych ani resolvera makro; parser nadal tylko normalizuje nazwę przed dopasowaniem.
- Backup pozostaje v7.

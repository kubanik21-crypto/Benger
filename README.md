# Benger 1.0.11 — Realistyczna arena

Build `92a319f`, source branch `feature/basketball-visual-polish`.

[Download APK](https://raw.githubusercontent.com/kubanik21-crypto/Benger/refs/heads/android-apk-downloads-1.0.11/Benger-1.0.11-92a319f.apk)

Install over the existing Benger 1.0.6–1.0.10. Do not uninstall. Same signing certificate, application ID and local data store.

Pięć nowych realistycznych scen zastępuje schematyczne sylwetki: rozgrzewka, kozłowanie, pierwszy mecz, rzut w pełnej arenie i wykończenie przy koszu. Fikcyjni zawodnicy, perspektywa hali, światło i odbicia na parkiecie. Oryginalna, wygenerowana grafika jest zapisana lokalnie (około 300 KB); aplikacja nie wywołuje AI ani nie pobiera obrazów z sieci.

Czytelniejsza tablica wyniku i skróty. Nagłówek nadal pokazuje datę i dzień tygodnia. Punktacja, tygodniowe zasady i historia pozostają bez zmian. Widżet dopasowuje układ do rozmiaru i orientacji telefonu. Grafika zmienia się z poziomem; drobna zmiana kadru następuje przy zmianie punktów, bez pętli animacji w tle.

Po aktualizacji otwórz Bengera i odśwież widżet przez ↻. Dotknij boiska, aby zobaczyć większy podgląd aktualnej areny. Jest też przycisk „Zobacz swoją arenę” w Więcej → Ustawienia. Krótkie wejście podglądu respektuje ograniczenie ruchu. Przytrzymanie widżetu pozwala zmienić rozmiar.

SHA256: `eea66f64cef910d19311b3bc1886b2511d666121b6f88595f9de0e22546e81c5`.

No signing keys, user photos or personal backups are included. Only the APK is published here; production web and AI Worker are unchanged.

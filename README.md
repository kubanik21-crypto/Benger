# Benger 1.0.12 — Ruchomy rzut

Build `eacc595`, source branch `feature/arena-motion`.

[Download APK](https://raw.githubusercontent.com/kubanik21-crypto/Benger/refs/heads/android-apk-downloads-1.0.12/Benger-1.0.12-eacc595.apk)

[Shot demonstration GIF](https://raw.githubusercontent.com/kubanik21-crypto/Benger/refs/heads/android-apk-downloads-1.0.12/Benger-shot-demo.gif)

Install over Benger 1.0.6–1.0.11. Do not uninstall. Same signing certificate, application ID and data store.

Po aktualizacji otwórz Bengera. Na widżecie naciśnij ▶. Piłka poleci po łuku do kosza, a po klipie wróci zwykła scena. Rzut uruchamia się też po zdobyciu punktów w tym samym tygodniu. Sam pokaz nie daje punktów.

Dotknij boiska → „Odtwórz rzut” w większym podglądzie. Odtwarzanie jest jednorazowe i trwa 1,5 sekundy. Możesz je powtórzyć. Zamknięcie lub ukrycie aplikacji zatrzymuje podgląd, a ograniczenie animacji jest respektowane.

Widget ma 13 klatek (około 8/s); płynność zależy od launchera Samsunga. Podgląd w aplikacji jest płynniejszy. Zawodnik pozostaje w fotograficznej pozycji rzutu, porusza się piłka. Bez nowych usług, alarmów i uprawnień. Grafiki i animacja działają offline.

GIF pokazuje klatki z tego samego renderera i jest zapętlony wyłącznie jako demonstracja. W aplikacji oraz widżecie klip kończy się sam.

SHA256 APK: `57effeb06abcc756c1e518016853ee6cc1e9f7535ddfa9c79a7201c503c3f993`.

No signing key or user data is included. No production web or AI Worker deployment.

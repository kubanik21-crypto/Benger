# Benger 1.0.14 — interaktywne wykresy

[Pobierz aktualizację APK](https://raw.githubusercontent.com/kubanik21-crypto/Benger/refs/heads/android-apk-downloads-1.0.14/Benger-1.0.14-ed64819.apk)

Build `ed64819`. Instaluj na obecnym Bengerze bez odinstalowywania. Zachowuje identyfikator, podpis i magazyn danych. Można pominąć 1.0.13 — ta aktualizacja zawiera również odczyt składników ze screenów.

Wykresy Dziennika, Progresu i historii ćwiczeń mają daty i jednostki, odczyt punktu dotykiem, przyciski przejścia między terminami, zakresy i widoczne serie, większy widok oraz tabelę. Podsumowanie średniej/min/max/zmiany jest rozwijane. Ciśnienie i tętno mają osobne skale, a wykresy żywienia uwzględniają historię celów. Brak dnia nie jest dopisywany jako zero kcal. Wybór B/T/W jest w podsumowaniu Dziennika.

Wszystko działa lokalnie i offline; bez nowego backendu lub zależności sieciowych. Webowa produkcja, main i AI Worker pozostają bez zmian.

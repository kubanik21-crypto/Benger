# Benger 1.0.7 — skaner w przepisach

APK: Benger-1.0.7-71a5bca.apk
Build: 71a5bcaf34ac8f3ecbdbe710f26f8f5a5892fd43

## Gdzie skanować

Przepisy → nowy przepis lub edycja → + Dodaj składnik z katalogu / Wybierz produkt i ilość → Zeskanuj produkt.
Dostosuj tę porcję → Zamień produkt / Dodaj składnik → Zeskanuj produkt.
Dziennik → propozycja posiłku z tekstu/głosu → Zeskanuj produkt przy wybranej pozycji.

Po kodzie wybierany jest dokładny produkt ze źródeł dotychczasowego repozytorium: własny produkt, cache, OFF. Sprawdź ilość i zatwierdź użycie składnika. Anulowanie pozostawia poprzedni wybór. Kod można także wpisać ręcznie.

## Instalacja

Na nowym Bengerze 1.0.6 jest to zwykła aktualizacja APK: nie odinstalowywać aplikacji. Podpis, applicationId, origin i magazyny pozostają te same. Przed aktualizacją warto wykonać pełny backup.

Jeśli telefon ma nadal starego Bengera 1.0.5 ze starym podpisem, Android odrzuci aktualizację. Nie usuwać starej aplikacji bez świeżego pełnego backupu zachowanego poza aplikacją. Pierwsze przejście wymaga kontrolowanej reinstalacji i importu danych; kolejne aktualizacje zachowują nowy podpis.

Brak zmian main, produkcji WWW i Workera AI. Klucze prywatne i dane użytkownika nie są publikowane.

Weryfikacja: 1500 testów Node, 333 testy Chromium; assembleRelease, lintRelease i apksigner.

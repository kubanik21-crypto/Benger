# Benger 1.0.9 — Widżet Dzisiaj

Build `3c9ad30`, source branch `feature/today-widget`.

[Download APK](https://raw.githubusercontent.com/kubanik21-crypto/Benger/refs/heads/android-apk-downloads-1.0.9/Benger-1.0.9-3c9ad30.apk)

Install over Benger 1.0.6, 1.0.7 or 1.0.8. Do not uninstall the existing app. Same application ID, private data store and signing certificate.

Po aktualizacji otwórz Bengera. Następnie przytrzymaj puste miejsce na ekranie głównym Samsunga → Widżety → Benger → Dzisiaj. Możesz też użyć Więcej → Ustawienia → Dodaj widżet na ekran główny. Zostaw około 4 × 4 pola; widżet można powiększyć.

Widżet pokazuje dzisiejsze kcal, cel i pozostałe kcal oraz trening. Skróty + Posiłek i + Waga otwierają istniejące formularze. Dane są lokalne; widoczna godzina oznacza ostatnie przeliczenie w aplikacji. ↻ otwiera Bengera, by pobrać świeże dane. Android może opóźniać odświeżanie w tle.

SHA256: `067f10359c683125cc1914dbc13684c0323dc4d8c44f39410a5826b84e1d7442`.

No private signing key or personal backup is included. This branch publishes only the APK, not the production web app or AI Worker.

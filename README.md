# Benger 1.0.15 — lepszy import składników

[Pobierz aktualizację APK](https://raw.githubusercontent.com/kubanik21-crypto/Benger/refs/heads/android-apk-downloads-1.0.15/Benger-1.0.15-29b481b.apk)

Build `29b481b`. Instaluj na obecnym Bengerze bez odinstalowywania. Zachowuje identyfikator, podpis i magazyn danych. Zawiera również wykresy z 1.0.14.

Przepisy → szkic lub edycja → Wczytaj składniki ze screena → wybierz obraz → Rozpoznaj listę składników. Wykrywamy rzeczywisty nagłówek i koniec listy; znaleziony obszar jest odczytywany ponownie. Możesz zaznaczyć samą listę palcem albo suwakami. Dla kilku obrazów zaznaczenia są osobne.

Przypadkowe napisy i przyciski strony nie są automatyczną listą składników. „Przygotowanie” kończy listę również bez dwukropka. Gdy nie ma wiarygodnych wyników, wybierz obszar lub popraw tekst zamiast zapisywać śmieci. „3 czubate łyżki” zachowuje liczbę i opis, bez zgadywania gramów. Sprawdź wynik przed zatwierdzeniem. OCR nie gwarantuje bezbłędnego rozpoznania dowolnej strony.

Odczyt i obraz pozostają na urządzeniu, również offline. Żaden Worker/AI/backend ani webowa produkcja/main nie są zmieniane.

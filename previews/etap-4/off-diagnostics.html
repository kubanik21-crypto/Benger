Ręczny test rzeczywistego API. Wykona jedno wyszukiwanie „mleko 2%” oraz odczyt kodu 3017620422003 (Nutella). Korzysta z tego samego providera co aplikacja, bez mocków i bez zapisywania wpisów w dzienniku.


    
    
Dlaczego wyszukiwanie nie działa?

    
Porównaj ten sam CGI GET z X-User-Agent, bez własnych nagłówków i z samym Accept, a następnie Search-a-licious. Test nie zmienia konfiguracji aplikacji. Potrwa około 30–60 sekund, z przerwami respektującymi limity.

    
    

    

    
A wymaga preflight OPTIONS. B i C są prostymi GET bez preflight wymuszonego nagłówkami. Zobacz faktyczny OPTIONS w DevTools → Network. Brak odpowiedzi nadal może oznaczać CORS, timeout lub błąd serwera.

    
Brak odczytywalnej odpowiedzi nie pozwala JavaScriptowi odróżnić CORS od blokady sieci. Szczegóły są w zakładkach Console i Network przeglądarki. Test nie gwarantuje poprawności danych etykiety.
